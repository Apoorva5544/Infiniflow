Drop-in API. Up in Minutes.

Query with full streaming SSE responses and granular chunk provenance with standard HTTP requests.

bash - infiniflow-query.sh
POST /api/v1/workspaces/{id}/query
# 1. Execute query with token streaming and citations enabled
curl -X POST https://infiniflow.onrender.com/api/v1/workspaces/ws_legal_corp/query \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5..." \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What was the operating margin and YoY growth?",
    "stream": true,
    "include_citations": true,
    "similarity_threshold": 0.75
  }'
# 2. Server-Sent Events (SSE) Response Stream (illustrative shape):
data: {"token": "Operating", "done": false}
data: {"token": " margin", "done": false}
